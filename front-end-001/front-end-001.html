Flexbox & Grid

Flexbox (Flex)

One-Dimensional Layout

Click me!

    Lays out direct child elements along a single axis and distributes remaining space

  • Optimized for layouts that stretch or shrink according to item size
  • Content-First-Approach
    Starts from inner content and expands outward

Grid

Two-Dimensional Layout

Click me!

    Arranges direct child elements on a virtual two-dimensional matrix

  • Optimized for layouts that divide space first and place elements into designated cells
  • Layout-First-Approach
    Starts from partitioning the parent container and places items inside
